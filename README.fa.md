# 🧊 کلود کیوب (Cloud Cube) — پلتفرم فروش، اتوماسیون ESXi و مانیتورینگ سرور مجازی

پلتفرم جامع **کلود کیوب (Cloud Cube)** شامل وب‌سایت فروشگاهی، پنل کاربری مشتریان، پنل مدیریت و اکانتینگ پیشرفته، سیستم تیکتینگ چندبخشی (پشتیبانی، فروش، مالی)، احراز هویت کد ملی (KYC)، تایید فیش واریزی (در پنل و ربات تلگرام با پروکسی SOCKS5 ایران) و اتوماسیون کامل **VMware ESXi** (ساخت آنی VM با Cloud-Init، ارتقای خودکار CPU/RAM/SSD، اسنپ‌شات، تغییر IP و مسدودسازی خودکار پورت هنگام اتمام ترافیک).

---

## 🚀 نصب سریع و دائمی روی سرور لینوکس (Ubuntu / Debian)

با اجرای دستور زیر روی سرور، پروژه در مسیر `/opt/cloudcube` نصب شده، به صورت **سرویس دائمی `systemd` (`cloudcube`)** در پس‌زمینه اجرا می‌شود و پس از ریبوت سرور نیز به صورت خودکار بالا می‌آید:

```bash
git clone https://github.com/Unknown-sir/X-monitoring.git /opt/cloudcube && cd /opt/cloudcube && sudo bash install.sh
```

یا اگر فایل‌های پروژه را از قبل در سرور دارید:
```bash
sudo bash install.sh
```

پس از اتمام نصب، پنل روی پورت **5000** (`http://YOUR_SERVER_IP:5000`) به صورت دائمی در دسترس خواهد بود.

## 🔄 آپدیت تک‌دستوری از گیت‌هاب

هر زمان نسخه جدیدی روی مخزن گیت‌هاب قرار گرفت، بدون نیاز به تنظیم مجدد یا از دست رفتن دیتابیس (`database.db`، `.env` و فیش‌ها)، فقط با یک دستور زیر پروژه را آپدیت و سرویس را ری‌استارت کنید:

```bash
cloudcube-update
```

---

## 🛠️ دستورات مدیریت سرویس دائمی

| دستور | عملکرد |
| :--- | :--- |
| `cloudcube status` | مشاهده وضعیت لحظه‌ای سرویس |
| `cloudcube logs` | مشاهده زنده لاگ‌های برنامه و ربات تلگرام |
| `cloudcube restart` | ری‌استارت کردن سرویس پنل و مانیتورینگ |
| `cloudcube-update` | دریافت آخرین آپدیت از گیت‌هاب و ری‌استارت خودکار |

## ✨ امکانات کلیدی سیستم
- **اتوماسیون کامل ESXi:** ساخت خودکار سرور اوبونتو از روی Golden Image، تزریق IP و پسورد با `Cloud-Init (seed.iso)`، ارتقای خودکار CPU / RAM / SSD پس از تایید فیش، اسنپ‌شات و قطع/وصل سخت‌افزاری vNIC.
- **تایید فیش واریزی دوطرفه (پنل + ربات با پروکسی SOCKS5):** ارسال آنی فیش به تلگرام مدیر و پنل وب با قفل یک‌بارمصرف و ثبت علت رد درخواست.
- **اکانتینگ و سطح دسترسی ماژولار (RBAC):** ساخت اکانت پشتیبان فنی، بخش فروش، مدیر و مشتری با فعال/غیرفعال کردن تک‌تک بخش‌های پنل.
- **احراز هویت مشتریان (KYC):** اعتبارسنجی ۱۰ رقمی کد ملی با الگوریتم Modulo-11 (قابل اجباری/اختیاری کردن توسط مدیریت).
