**XMonitor** یک سامانه جامع، سبک و سریع برای مدیریت، مانیتورینگ ترافیک سرورهای لینوکسی و اتوماسیون کامل مجازی‌ساز **VMware ESXi** است که با زبان **پایتون (Flask + SQLAlchemy + Paramiko)** و **Redis** توسعه داده شده است.

این سامانه مخصوص شرکت‌های هاستینگ، مدیران سرور و فروشندگان سرور مجازی (VPS) طراحی شده تا فرآیند ساخت ماشین مجازی اوبونتو، ریبیلد، تنظیم خودکار شبکه با Netplan، مانیتورینگ مصرف ترافیک ماهانه و مسدودسازی هوشمند پورت شبکه هنگام اتمام ترافیک را به صورت ۱۰۰٪ خودکار مدیریت کنند.

---

## قابلیت‌های کلیدی

### 🚀 اتوماسیون مجازی‌ساز ESXi از طریق SSH
- **ساخت خودکار سرور مجازی اوبونتو:** کلون آنی دیسک از روی ایمیج مرجع (Golden Image) با دستور بهینه `vmkfstools -i -d thin`، افزایش سایز دیسک، تولید فایل سخت‌افزاری `.vmx` و رجیستر خودکار در ESXi با دستور `vim-cmd solo/registervm`.
- **ریبیلد آنی سرور (One-Click Rebuild):** جایگزینی خودکار دیسک سیستم‌عامل سرور با تمپلیت اولیه بدون نیاز به حذف و ثبت مجدد ماشین، در کمتر از ۱ دقیقه.
- **ساسپند سخت‌افزاری شبکه در اتمام ترافیک:** برخلاف راهکارهای قدیمی که سرور را خاموش می‌کردند، ورکر به محض اتمام سقف ترافیک فقط کارت شبکه مجازی را در سطح ESXi قطع می‌کند (`vim-cmd vmsvc/device.connection <vmid> 4000 0`). ماشین روشن می‌ماند اما ترافیک ورودی و خروجی آن به صفر می‌رسد تا دیتای مشتری آسیبی نبیند.
- **آزاد‌سازی خودکار شبکه پس از شارژ ترافیک:** به محض اینکه مشتری یا ادمین از طریق پنل وب یا ربات تلگرام ترافیک سرور را شارژ کند، کارت شبکه سرور بلافاصله در ESXi وصل و اینترنت آن وصل می‌شود (`connected = True`).
- **مدیریت کامل آی‌پی و Netplan اوبونتو:** امکان تعریف آی‌پی اصلی، پیشوند (CIDR)، گیت‌وی، آی‌پی و گیت‌وی IPv6 و آی‌پی‌های اضافه، همراه با اعمال آنی از طریق SSH با دستور `sudo netplan apply`.

#### ساختار استاندارد فایل Netplan تولید شده (`/etc/netplan/01-netcfg.yaml`):
```yaml
network:
  version: 2
  renderer: networkd
  ethernets:
    eth0:
      dhcp4: false
      dhcp6: false
      addresses:
        - 185.42.212.241/25
        - 2a13:9540:0000:0034:0000:0000:29ec:b785/64
      routes:
        - to: 0.0.0.0/0
          via: 185.42.212.129
        - to: ::/0
          via: 2a13:9540:0:34::1
      nameservers:
        addresses: [8.8.8.8, 8.8.4.4, 2001:4860:4860::8888, 2001:4860:4860::8844]
```

### 📊 داشبورد وب و مانیتورینگ زنده
- سطوح دسترسی سه‌گانه: **Owner (مالک اصلی)**، **Admin (مدیر)** و **User (مشتری)**.
- نمایش لحظه‌ای منابع سرور: پردازنده (تعداد هسته و درصد مصرف)، رم، ترافیک زنده دانلود و آپلود بر حسب Mbps، دیسک، خواندن و نوشتن دیسک و پینگ سرور.
- نمودارهای تاریخچه مصرف ترافیک با **Chart.js**.
- کش قدرتمند و بهینه‌سازی بار دیتابیس با **Redis**.
- ارسال هشدارهای خودکار از طریق **ایمیل (SMTP)** و **ربات تلگرام**.

### 🤖 ربات تلگرام هوشمند و تعاملی
- منوی دکمه‌ای اینلاین برای مشاهده سرورها، مصرف ترافیک و وضعیت پورت شبکه.
- دستور `/recharge` برای شارژ ترافیک سرور و فعال‌سازی مجدد شبکه مسدود شده.
- دستور `/setlimit` برای تغییر سقف مجاز ترافیک (مخصوص مالک پنل).
- سیستم تیکتینگ و ارسال اطلاعیه همگانی به مشتریان.

## پیش‌نیازها

برای اجرای کامل سیستم:
- پایتون 3.10 یا جدیدتر
- سرور ردیس (Redis)
- هاست ESXi با دسترسی SSH (نسخه 6.7، 7.0 یا 8.0)
- پکیج `vnstat` روی ماشین‌های مجازی اوبونتو

## نصب و راه‌اندازی سریع

### ۱. کلون کردن ریپازیتوری
```bash
git clone https://github.com/Unknown-sir/X-monitoring.git
cd X-monitoring
```

### ۲. ساخت محیط مجازی و نصب پیش‌نیازها
```bash
python3 -m venv .venv
source .venv/bin/activate  # در ویندوز: .venv\Scripts\activate
pip install --upgrade pip
pip install -r requirements.txt
```

### ۳. تنظیم متغیرهای محیطی
فایل‌های نمونه را کپی کنید:
```bash
cp .env.example .env
cp config.example.json config.json
```
سپس فایل `.env` را باز کرده و توکن تلگرام، چت آیدی ادمین و رمز عبور دلخواه برای کاربر Owner را وارد نمایید.

### ۴. اجرای برنامه
```bash
python app.py
```
پنل وب به‌صورت پیش‌فرض روی آدرس `http://localhost:5000` در دسترس خواهد بود.
